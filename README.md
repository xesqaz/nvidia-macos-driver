# Pascal / GTX 1050 для macOS

Разработка macOS-драйвера для **NVIDIA Pascal**, начиная с настольной **GeForce GTX 1050 (GP107, 2 ГБ)**. Это отдельная линия разработки в форке [xesqaz/nvidia-macos-driver](https://github.com/xesqaz/nvidia-macos-driver), основанная на NullMoth v2.3.6.

Практическая цель — аппаратное ускорение, Metal, рабочий стол, Minecraft Java и обычные приложения для повседневной работы и разработки. Первый целевой выпуск системы — macOS 15 Sequoia x86_64. Поддержка других Pascal-карт и macOS 26 потребует отдельных проверок.

## Текущее состояние

**Этап 0: определение карты, проверка firmware и подготовка аппаратного backend.** Ускорение Pascal в macOS пока не реализовано. Готовые релизы и установщики оригинального NullMoth предназначены для его поддерживаемых GPU; название этого форка не делает их совместимыми с GTX 1050.

| Компонент | Состояние |
|---|---|
| Аппаратный baseline GP107 | Получен; архив и 98 контрольных сумм проверены |
| Compute/render на нашей GTX 1050 под Linux NVK | Оба теста прошли без ошибок результатов |
| Переносимое ядро `pascal/` | Распознаёт PCI/BAR, состояние питания, `BOOT_0` и цепочку VBIOS |
| Инструменты отчёта и трасс | Различают завершённый скан, потери событий и неподдержанные записи |
| `PascalProbe.kext` | Диагностические исходники; сборка и загрузка на macOS ещё не проверены |
| Pascal firmware/MMU/FIFO backend | Следующий этап; пока не реализован |
| macOS Metal / framebuffer / Minecraft | Предстоят реализация и реальные испытания |

[Данные аппаратной проверки](pascal/docs/BASELINE.md) · [Описание кода и сборка](pascal/README.md)

## Проверить код без macOS

Из корня репозитория:

```sh
cmake -S pascal -B pascal/.build -DCMAKE_C_COMPILER=clang -DPASCAL_SANITIZE=ON
cmake --build pascal/.build
ctest --test-dir pascal/.build --output-on-failure
```

Это проверяет переносимое C-ядро и инструменты на CPU. Оно не запускает firmware, не меняет драйвер Linux и не является тестом Metal в macOS.

## Порядок разработки

1. Проверить исходные данные реальной GP107 и код определения карты — выполнено для этапа 0.
2. Собрать и испытать диагностический модуль на macOS: точное определение устройства и чтение `BOOT_0`.
3. Реализовать Pascal backend: firmware/Falcon/ACR, память, MMU и FIFO. Использовать Nouveau как аппаратный reference и сравнивать результаты с нашей картой.
4. Подтвердить выполнение маленькой команды на GPU с проверкой результата.
5. Подключить GPU backend к NVK/Metal, затем отладить вывод изображения, WindowServer и нужные приложения.

Трассы используются для анализа и сравнения. Слепого воспроизведения записей MMIO здесь нет: они зависят от состояния устройства и DMA-адресов и не заменяют драйвер.

## Связь с NullMoth

Исходный графический стек, translator и Mesa/NVK-порт сохранены как база для изучения и последующей интеграции. Низкоуровневый GSP/RM-путь upstream рассчитан на Turing и новее; GP107 требует другой реализации. Простое добавление PCI ID в установщик не даёт Pascal-ускорения.

- [Оригинальный проект NullMoth](https://github.com/nullmoth/nvidia-macos-driver)
- [Документация базы v2.3.6](https://github.com/nullmoth/nvidia-macos-driver/tree/637282334617d27bccf8aa2448497c0f19465dc8)
- [Граница поддержки GPU в upstream](https://github.com/nullmoth/nvidia-macos-driver/blob/637282334617d27bccf8aa2448497c0f19465dc8/docs/CARD-SUPPORT.md)

Сырые отчёты, VBIOS и идентификаторы оборудования в репозиторий не включены. Исходные лицензии и уведомления сохранены; см. [LICENSE](LICENSE) и [NOTICE](NOTICE). Сторонние Nouveau/Mesa/firmware сохраняют собственные условия лицензирования; этот форк их не меняет.
